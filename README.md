# Контрольная работа №2 — «Конфетти»: сайт поиска и найма аниматоров

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание
Многостраничный сайт на Bootstrap 5.3.8 (CDN) для поиска и заказа аниматоров на детские праздники.

## Страницы
- `index.html` — оффер, популярные программы, топ аниматоров, «Как это работает», отзывы (carousel)
- `catalog.html` — карточки аниматоров: фото, рейтинг, цена «от», формат
- `advantages.html` — преимущества сервиса: плюсы, цифры, сравнение с другими способами поиска
- `blog.html` — как выбрать аниматора, сценарии по возрастам (tabs), идеи тем
- `contacts.html` — форма заявки, мессенджеры, телефон, график работы, FAQ (accordion)

## Подключение Bootstrap
CDN (CSS и JS Bundle). `css/custom.css` подключён после Bootstrap.

## Компоненты Bootstrap
`container/row/col-*`, `g-*`, `navbar`, `card`, `btn`, `badge`, `alert`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `carousel`, `tabs`, `breadcrumb`, `list-group`, `table-responsive`.

## Самостоятельные доработки
- единый navbar на всех страницах, валидация форм без перезагрузки
- SEO: title, description, Open Graph, семантика, хлебные крошки
- валидация форм Bootstrap, SVG-иллюстрации в `images/`

## Структура
`index.html`, `catalog.html`, `blog.html`, `contacts.html`, `css/custom.css`, `js/`, `images/`, `README.md`, `.gitignore`

## Стандарты оформления кода
- HTML5: `<!DOCTYPE html>`, `lang="ru"`, семантические теги (`nav`, `main`, `header`, `article`, `aside`, `footer`), один `h1` на странице, иерархия заголовков без пропусков
- Отступ 2 пробела, строки до 100 символов, длинные теги — по одному атрибуту на строку, двойные кавычки, комментарии-разделители секций
- Доступность: `label` у всех полей, `alt` и `width/height` у изображений, `aria-*` у навигации, ссылка «Перейти к содержимому», видимый фокус
- CSS: оглавление, переменные `:root`, секции с комментариями, только точечные правки поверх Bootstrap
- JS: `'use strict'`, IIFE, комментарии к функциям
